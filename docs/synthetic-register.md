# The Synthetic Register

A **synthetic** is any behaviour the guest kernel is shown that did not come from Sony:
a faked device response, an invented table value, a boot parameter the loader would
normally supply, a hypercall answered by the harness, a skipped call into code the dump
does not contain. The kernel cannot tell the difference — which is exactly why each one is
dangerous, and why every one is written down here.

This register is the accounting the project's narrative rests on. Three rules make it worth
trusting:

1. **Registered.** Every synthetic has a row: its address, what it pretends to be, what the
   kernel actually receives, when it was introduced, and the blast radius if it is wrong.
   Nothing reaches the kernel that is not in this table.
2. **Observable.** Every synthetic announces itself in the boot log. The trampoline prints a
   `SYNTH:` line naming the kernel-side fakes and the live patch count; the harness prints a
   `SYNTH-HARNESS:` line for the debugger-side injects. A fake that lives silently in a binary
   is indistinguishable from a fact, so none of these do — they are loud by construction.
3. **Revertible.** Each row names the condition under which it is retired ("REVERT at …") and
   cites the experiment (`L-xxx`) that introduced it. A synthetic is a placeholder for a part
   of the platform we have not yet modelled, not a permanent edit. The patch-reduction program
   (see [`../METHODOLOGY.md`](../METHODOLOGY.md)) is the act of removing them.

**Reading the table.** `Where` is a guest virtual address unless marked otherwise. `Returns /
writes` is what the kernel receives from the fake, not what the fake intends. `Attribution
risk` flags a synthetic whose wrong value could masquerade as genuine kernel behaviour — the
`HIGH` rows are the ones to rule out first before trusting anything downstream of them.

The naming: `S-xx` are the synthetics; `P-xx` are the trampoline patch sites that implement
them; `L-xxx` are the logged experiments. The register is append-only and updated in place —
the live copy governs; this is the public snapshot at Phase 2 completion.
